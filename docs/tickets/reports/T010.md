## Deviations and follow-ups

- **Human:** put a Stripe **test** key (`sk_test_…`) in the main `.env` and in Vercel, then re-run AC1, AC2 (valid path) and AC3. The key there now is `rk_live_…` and shouldn't be used before launch.
- **Human, before merge:** set `NEXT_PUBLIC_SITE_URL` in Vercel. `src/env.ts` now requires it, and `payload.config.ts` imports env, so a deploy without it fails to build. `STRIPE_SECRET_KEY` is optional in the schema so that CI and builds run without it; creating or reading a session without it logs an error and returns 502 or the unconfirmed state.
- An invalid amount from a browser form post (`Sec-Fetch-Mode: navigate`) redirects back to `/donate?error=amount`, so the donor sees the CMS error copy. Other clients get the 400 the AC specifies.
- Source page: `document.referrer` doesn't change on client-side navigation, so a small `PageTrail` client component in the root layout keeps the previous path in `sessionStorage`. The donate form sends it as `source_page`, and the server accepts it only if it's a same-site path, otherwise `/donate`. It is the `cancel_url` and goes in `metadata`.
- The Stripe product name is the `header` global's `brandTitle`, so no new CMS field or migration is needed. Add a `donation-settings` field if Amagi wants different wording on Stripe's page.
- `donation_complete` calls `trackDonationComplete({ value, currency })` in `src/lib/tracking`, a no-op stub for T015, which also adds once-per-session deduplication.
- Removed: the mockup banner, `/donate/checkout` and `donate/mockup.ts`. The amount helpers moved to `src/utils/donation.ts`.
