## Deviations and follow-ups

- The backfill now adds `role` nullable, sets `admin` where it is null, then sets the `editor` default and `NOT NULL`. The first draft updated `role = 'editor'` rows, which would promote real editors if the SQL ever re-ran.
- `role` is required in the generated types, so `tests/helpers/seedUser.ts` now creates the e2e user as `admin`.
- A fresh database's first user (via `first-register`) gets the `editor` default. Not covered by this ticket; worth a follow-up so the first registered user becomes `admin`.
