## Deviations and follow-ups

- SPEC §5.2 `donation-settings` gained `thankYouKicker` (`{amount}` placeholder), `thankYouLinkLabel` and `unconfirmedLinkLabel`, and the `page` group's hint and error copy take a `{minimum}` placeholder. Without them the thank-you and donate pages' current copy couldn't move into the CMS unchanged (§6.4). SPEC updated in this PR.
- The local Supabase databases have no automatic-RLS event trigger, so the migration ends with an idempotent `ENABLE ROW LEVEL SECURITY` on any public table that lacks it, following `enable_rls`.
- Form keys (§8.3) live in `src/config/forms.ts` for reuse by the `form` block and `form-submissions` (T007, T012).
- `forms.thankYou` and each dropdown list reject duplicate keys or values.
- Out of scope as planned: frontend rendering (T009), seed values and the content migration (T011), Substack fields on `integrations` (T028).
