## Deviations and follow-ups

- No SPEC §6.3 divergence. Choices inside it: `cardGrid` item `title` is optional (the safeguard badges have body text only); the `actionAreas` link and hero secondary link are optional `{ label, href }` groups; `roadmap` step `when` is optional (the Call to Action process has none); `newsTeaser` has `limit` and `linkLabel`; `faqList` filters on a `category` text field matching `faqs.category`.
- Anonymous reads of `partners` and `supporters` return only published, `permissionConfirmed` entries (`src/access/publishedAndPermittedOrAuthenticated.ts`), so unpermitted names can't leak through the REST API or `news.partner` population. Verified: anonymous count 0, then 1 after setting `permissionConfirmed`.
- `supporters.level` is a select of the four current level names (stored as an enum, so new levels need a migration). `faqs.answer` is plain text, matching today's copy.
- Hero countdown `target` is a date field and reads back in UTC: T011 should send `2026-11-16T05:00:00.000Z` for midnight in Kingston.
- The `flow` diagram's icons stay fixed by position in the renderer (they're design, not copy), as on `main`.
- Revalidation runs on publish and unpublish only (not draft autosaves). Pages revalidate their own path (`home` → `/`); news revalidates `/`, `/news` and the item; partners, supporters and FAQs revalidate the whole site layout, since any page's blocks can show them. Scripts can pass `context.disableRevalidate`.
