## Deviations and follow-ups

- **Lint was broken on `main`.** ESLint loaded `eslint.config.js`, which imported `@payloadcms/eslint-config` (not installed). `eslint.config.mjs` used `FlatCompat`, which fails with `eslint-config-next` 16. Rewrote `eslint.config.mjs` to Next 16's native flat config. It then flagged a bare `<a href="/">` on Coming Soon, now `<Link>`.
- **`allowBuilds`:** `esbuild` and `unrs-resolver` were `false` in `pnpm-workspace.yaml` but allowed in `onlyBuiltDependencies`; moved as `true`, with `sharp` and `supabase`.
- **Supabase config:** realtime, edge functions and analytics turned off (unused). `supabase/.gitignore` rules moved to the root `.gitignore`.
- **`next dev` writes an agent-rules block into `CLAUDE.md`** and re-adds it on every run. Committed so the tree stays clean for preflight.
- **Follow-up: no favicon.** Needs a brand asset; belongs with T005 or T009.
- **Sandbox note:** under Claude Code's sandbox, the `tsx` CLI can't open its IPC socket and the Supabase CLI can't write `~/.supabase`. `node --import tsx scripts/<name>.ts` and `DO_NOT_TRACK=1` work around them; neither affects normal terminals.
