## Deviations and follow-ups

- `styles.css` was split into `tokens.css` (custom properties), `base.css` (reset, typography, focus, skip link, reduced motion) and `styles.css` (Coming Soon page rules only). The layout imports all three.
- The `@keyframes coming-soon-image-cycle` is injected inline in `page.tsx` (dynamic per image count) — not in CSS — so it is unaffected by the split.
- Adobe Fonts does not support `font-display` via URL parameter. The kit (`ebg5tit`) currently serves `font-display:auto` on all 8 `@font-face` rules (reviewer probe), so the scope item "loaded with `display=swap`" is **not met** in code: the setting lives in the fonts.adobe.com web project (Web Projects → font-display → swap). Human action required.
