## Deviations and follow-ups

- **Content migration and future schema changes.** `20261007_144558_t011_content` writes through the Local API with the current config. Once a later migration adds a column to `pages`, `news`, `faqs` or one of the seeded globals, a fresh `pnpm payload migrate` would fail at this step (the config expects the column, the schema doesn't have it yet). Production and the pulled database are unaffected (it has already run there). Options when that happens: guard the step, or have fresh databases skip it and run `pnpm db:seed` after migrating.
- Added small copy fields, so the last UI text on the blocks is in the CMS (one migration, `20261007_144302_t011_copy_fields`, columns only): hero countdown unit labels, `hostMap.anchorLabel`, `summitWeek.monthLabel`, `roadmap.statusLabels` (done/now/next) and `newsTeaser.showAll`. SPEC §6.3 updated.
- `/news` is a `pages` document (slug `news`) served by `[slug]`: photo hero, a `newsTeaser` with "list every item" (type label, `h2` headings when the section has no heading) and the Donate banner. SPEC §4.2 updated. The Home teaser is now newest first (SPEC §4.2); `main` listed the items oldest first.
- Partner announcements (SPEC §4.4): a partners `logoGrid` entry links to that partner's newest published announcement. No Release 1 page has a partners logo grid yet, so AC4 used a test page.
- Header, footer, donation-settings and cookie-consent now revalidate the whole site on publish (`revalidateGlobalAfterChange`). Checked with a REST update to `header.donateLabel`: the new label showed on `/about` straight away.
- Still in code: the news item's "All news" back link, landmark and aria labels ("Main", "Menu", "Footer", "The Summit in numbers", "Make a donation", "Status:"), and the not-found and error copy (the error page must not depend on the CMS). The News type labels ("News", "Partner announcement") are the select option labels in `src/config/news.ts`. Candidates for a later ticket.
- About's "How it works" and "Amagi's role" paragraphs in `placeholderContent.ts` were never rendered on `main`, so they weren't seeded (the About page matches `main`).
- `forms.thankYou` has placeholder copy for all five form keys; `dropdowns.audienceTypes` has the ten values from SPEC §5.3 with plain labels. Territories and industries are left empty for Amagi.
- The donate amounts moved to `donation-settings` too; `mockup.ts` keeps only the amount helpers that T010 replaces. Page titles come from each page's `meta.title`; the site and donate layouts fall back to the header's brand title.
- The migration's `down` leaves content in place (editors may have changed it).
- This branch is based on T009 (PR #26), which hasn't merged yet.
